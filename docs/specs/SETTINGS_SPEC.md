# 設定

`/settings` は deep link で直接開けます。テーマと言語を選択ダイアログで変更します。
ダイアログを閉じる、または現在値を選択した場合は保存しません。
テーマは端末に合わせる・ライト・ダーク、言語は日本語・English を表示します。
言語名は選択先自身の表記を使います。

保存中は操作を無効化し、進捗を表示します。テーマ・翻訳は保存成功後に切り替えます。
失敗時は直前の表示値を維持し、再試行を促す SnackBar と ErrorReporter の報告を行います。
同じ設定を選び直すことで再試行できます。

設定の所有者は `AppPreferencesController`、入力境界は `AppPreferencesUseCase` です。
保存形式・初回の言語解決は [アーキテクチャ](../ARCHITECTURE.md#保存形式と-locale) を参照してください。
ダイアログと設定一覧はスクロールに対応し、320px 幅・文字倍率 2.5 で widget test を行います。

# アプリを操作して確認する

[README の起動手順](../../../README.md#セットアップ) と
[画面仕様](../../../docs/specs/SPECS_INDEX_SPEC.md) に従う。
checkout・commit/dirty 状態・platform・端末・define・起動コマンドを記録する。
Marionette と Patrol は未導入。利用できるブラウザまたは端末操作ツールを使い、
実際の画面と要素を確認してから操作する。ツール追加を暗黙の前提にしない。
操作できない場合はその範囲を未検証とし、ビルドや Widget test を実操作と表記しない。

## 初期サンプルの観察点

1. ホームから設定へ進み、戻る操作と現在値の表示を確認する。
2. ライト・ダーク・端末設定を選び、反映と選択状態を確認する。
3. 日本語・English を切り替え、文言・折り返し・設定の選択値を確認する。
4. 同じ保存領域でアプリを再起動し、テーマと言語が復元されることを確認する。
5. 狭い画面と文字拡大でスクロール・操作・文字切れを確認する。

未設定時の端末 locale や保存失敗は、安全に用意できる専用環境・fake のテストで確認し、
実操作で観察できたものと分ける。ユーザーの保存値や既存端末を消去して条件を作らない。
自分で用意した環境・データ・起動プロセスを識別し、終了時はその範囲を片付ける。

## 証跡と報告

静的表示は PNG と表示条件、操作の問題は番号付き手順・期待値・実測値・関連ログを記録する。
必要なら動画も使い、撮影元 commit と確認範囲を添える。生ログの token や個人情報は公開資料へ含めない。
問題を再現できた回数、影響、未確認条件を記し、問題なしという結論は探索した範囲に限定する。
QA だけの依頼では修正、Issue 投稿、外部への証跡アップロードを行わない。
